# REX2-testfiler

Från VelociLoops (https://github.com/kunitoki/VelociLoops), `tests/data`, under Unlicense (public domain).

- `120Stereo.rx2`, `120Mono.rx2`, `120FourBeats.rx2`, `120ThreeBeats.rx2` (tre slag), `120Mono24Bits.rx2` (24 bitar): REX2-filer som `decodeRex` läser.
- `.wav` med samma namn: deras facit, så som REX-SDK:n spelar dem slice för slice i 120 BPM (med filens processing gain). `120Mono.wav` och `120FourBeats.wav` är samma fil.
- `ErrorCorrupt.rx2`: en trasig fil.
