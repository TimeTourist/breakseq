# REX2-testfiler

Från VelociLoops (https://github.com/kunitoki/VelociLoops), `tests/data`, under Unlicense (public domain).

- `120Stereo.rx2`, `120Mono.rx2`, `120FourBeats.rx2`: REX2-filer som `decodeRex` läser.
- `120Stereo.wav`, `120Mono.wav`, `120FourBeats.wav`: deras facit, så som REX-SDK:n spelar dem slice för slice i 120 BPM (med filens processing gain). `120Mono.wav` och `120FourBeats.wav` är samma fil.
- `ErrorCorrupt.rx2`: en trasig fil.
